GlitchTip

Simple, open source error tracking

Sentry was our favorite open source error tracker, and no it's no longer open source. We believe that a quality open source product should pick up where they left off, so we created GlitchTip.

GlitchTip is compatible with the Sentry API, so it can use their SDKs to receive error data from your application.
